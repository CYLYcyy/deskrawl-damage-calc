# deskrawl-damage-calc

`Deskrawl: Idle ARPG` 伤害期望倍率计算 Skill。用于对比配装、天赋、技能形态与覆盖率方案的优劣，以及判定某词条 / 天赋归入哪个乘区。采用「用户实测 > 官方页 > 第三方」的来源裁决，内置验算流程。

当前版本：**v1.0.0**（第一个正式发布版，2026-11-21）。

## 安装 / 使用

本仓库本身就是一个可直接安装的 WorkBuddy Skill 目录：将整个目录放到 `~/.workbuddy/skills/deskrawl-damage-calc/`，WorkBuddy 会自动加载 `SKILL.md`。无构建步骤、无外部依赖。

触发方式：提供面板数值与条件词条，要求估算 / 对比伤害倍率，或询问某加成归入哪个乘区。

## 能力边界

- 输出的是**单次命中的期望伤害倍率**（相对值，非绝对 DPS）。
- 框架跨职业、跨流派通用，但已查证的机制与数值案例**集中在法师**；计算其他职业前须先自行查证该职业机制，不得照搬法师结论。
- 不做：精确 DPS / 攻速循环精算、DoT 整周期总伤（只给单跳倍率）、充能指环精算（乘数 K 留白）。
- 不内嵌会随版本变动的具体技能跳数 / 每跳倍率，计算时须深度调查后按实际代入。

## 计算框架

每个组分独立执行分步计算，最后连乘：

```
组分倍率 = A_stat × A_ele × A_form × A_crit × A_cond × A_indep × 充能指环乘数
```

| 乘区 | 含义 | 关键约定 |
|---|---|---|
| `A_stat` | 主属性 | `1 + 主属性/100` |
| `A_ele` | 元素 | 全伤 INC 与元素 INC **加算**、不独立成区 |
| `A_form` | 形态 | 不同形态 INC 不相乘 |
| `A_crit` | 暴击 | 带覆盖率的暴 / 暴伤增益在乘区**内部**分段加权 |
| `A_cond` | 条件 | 各条件项 `INC × 覆盖率` 加算 |
| `A_indep` | 独立状态 | 静电、易伤内置 30% 等 `∏(1+x)`；层数按实战代入，不默认满层 |

复合伤害（多属性 / DoT / 爆炸等）必须先拆成单一组分分别计算，**组分之间不相乘、不合并**。带覆盖率的非线性增益须在乘区内部加权，不得在乘区外乘平均系数——这两条是历史重大算错的防范重点。

## 目录结构

| 文件 | 内容 |
|---|---|
| `SKILL.md` | Skill 入口与规则主体：定位、高优先级规则、三板块（伤害计算 / 天赋树 / 装备）、验算与输出规范 |
| `references/data-sources.md` | 数据源清单、**来源裁决规则唯一定义**、已裁决冲突案例、面板甄别、普攻 / 技能数值查法、装备词条效果 |
| `references/game-mechanics.md` | 形态 / DoT / 荆棘 / 暴击 / 状态增伤等机制的查证证据（含静电系数推导） |
| `references/known-issues.md` | 待实测清单、当前默认值、验证方法、历史算错教训 |
| `references/examples.md` | 端到端计算示例、法师电法路径案例 |
| `references/workflow.md` | 计算前提问清单、**实测方案设计**（替提问者出可执行实测） |

主体只保留规则与指针，易变的数值、来源冲突与案例下沉在 `references/`，便于长期复用与单独更新。

## 来源裁决

同一数值多来源冲突时：用户游戏内实测 > 官方数据页 > 第三方指南 > 社区传闻。官方页也会过时，出现「官方页 vs 第三方」冲突时不得直接判第三方过时，应提示用户游戏内核对。已由实测裁决的冲突记入 `data-sources.md`，未裁决的登记到 `known-issues.md` 并采用保守默认值。
