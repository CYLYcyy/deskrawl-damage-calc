# 案例与端到端示例

本文件收录两类案例：**端到端计算示例**（教学用，数值为虚构用例）与**法师电法路径案例**（职业 / 流派框架）。本文件不内嵌具体技能的跳数 / 每跳倍率——技能数值须在计算时深度调查后按实际代入。最后核对日期 2026-11-21。

## 端到端示例

### 示例一：单组分（含易伤内置 30% 独立乘区）

输入：法师火系普攻。主属性 200，全伤 INC 30%，火伤 INC 70%，普攻 INC 40%，暴击率 50%，暴伤 INC 100%。目标精英：易伤覆盖率 40%，易伤 INC 20%，健康 INC 30%，远处 INC 50% / 覆盖 60%，精英 INC 80% / 覆盖 20%，灼烧 INC 96% / 覆盖 50%。健康 / 受伤覆盖按精英常量 0.2 / 0.3（受伤 INC 未给按 0）。

```
主属性乘区 = 1 + 200/100            = 3.0
火伤乘区   = 1 + 全伤0.3 + 火伤0.7   = 2.0   ← 全伤与元素加算，不独立成区
形态乘区   = 1 + 0.4                = 1.4
暴击乘区   = 1 + 0.5×(0.5+1.0)      = 1.75
条件乘区   = 1 + 0.2×0.4 + 0.3×0.2 + 0×0.3
             + 0.5×0.6 + 0.8×0.2 + 0.96×0.5 = 2.08   ← 易伤仅计INC，不含内置30%
独立乘区   = 1 + 易伤内置0.3×0.4    = 1.12   ← 易伤内置30%在独立乘区
最终倍率   = 3.0×2.0×1.4×1.75×2.08×1.12 ≈ 34.25
```

验算：覆盖率与暴击归零后 `= 3.0×2.0×1.4 = 8.4`，等于三乘区连乘，退化测试通过。

### 示例二：复合伤害 + 光环覆盖率

输入：雷系普攻附火焰爆炸（两个组分）。主属性 100，雷伤 INC 50%，火伤 INC 40%，普攻 INC 20%，暴击率 40%，暴伤 INC 100%。雷系直伤 200% 武器伤；命中灼烧目标时 30% 概率触发 800% 武器伤火焰爆炸（独立组分）。光环：+10% 暴击 / +100% 暴伤，持续 5 秒 / 冷却 20 秒 → 覆盖 25%。易伤覆盖 50%（仅易伤内置 30%，无「对易伤伤害增加」INC），灼烧 INC 未点。无全伤 INC。

```
暴击乘区 = 0.75×[1+0.4×(0.5+1.0)] + 0.25×[1+0.5×(0.5+2.0)]
         = 0.75×1.6 + 0.25×2.25 = 1.7625     ← 光环在乘区内部加权
条件乘区 = 1 + 0×0.5 = 1.00   ← 无「对易伤伤害增加」INC；内置30%不在此区
独立乘区 = 1 + 易伤内置0.3×0.5 = 1.15   ← 对雷、火两组分均生效
雷直伤组分 = 2.0 × 2.0 × 1.5 × 1.2 × 1.7625 × 1.00 × 1.15 = 14.59
火爆炸组分 = (0.3×8.0) × 2.0 × 1.4 × 1.2 × 1.7625 × 1.00 × 1.15 = 16.34
```

要点：爆炸是独立组分，触发概率并入其基础倍率（`0.3×8.0`），不与雷直伤相乘；光环增益在暴击区内部分段加权，不在外部乘平均系数；易伤内置 30% 归独立乘区、对所有组分生效，而「对易伤伤害增加」才进条件区。

## 法师电法路径：攻击形态与技能轴（案例）

以下是法师雷系（电法）路径的形态与技能轴框架，供**估算命中频率**参考，不属于通用计算规则；其他职业 / 流派须自行查证。**本节不写死技能数值**——跳数、每跳倍率、普攻系数均须在计算时深度调查后代入。

**常用攻击形态**

| 攻击 | 形态 | 属性 / 组分 | 形态 INC 归属 |
|---|---|---|---|
| 闪电风暴 Lightning Storm | **强力攻击** | 雷 | 强力攻击 INC |
| 普攻 | **普攻** | 可为复合（雷 + 火等） | 普攻 INC |

- 两者**形态 INC 不同、严禁混用**：风暴吃「强力攻击伤害增加」，普攻吃「普攻伤害增加」。比值计算时必须各乘各的形态乘区（主体 Step 4）。
- **跳数 / 每段倍率必须深度调查**：闪电风暴的每发跳数、每跳倍率写在技能本身，普攻系数见 `data-sources.md`「普攻 / 技能数值查法」。计算命中频率前，须先从技能面板 / 参考网页查明这些值并按实际代入；不得凭记忆或默认值假定。
- **技能轴（发数 / 普攻穿插比）按用户实测取，不得默认**。命中频率是 DPS 校准的关键输入，带覆盖率 / 形态增益的方案对它尤其敏感；需实测时按 `workflow.md`「实测方案设计」取固定窗口读数。
