# 工作流：取数清单与实测方案设计

本文件是两份**操作辅助**材料：**计算前提问清单**（取数模板）与**实测方案设计**（替提问者出实测方案）。乘区归类与计算公式以主体 `SKILL.md` 为准，本文件不重复。两份清单都服务于主体「分步计算」，计算前先读本文件取数与定方案。最后核对日期 2026-11-21。

## 计算前提问清单（必要已知数据）

计算前按下列清单向用户取数；已有约定或默认值的项不必问，输出时声明即可。本清单是取数模板，乘区归类与计算公式仍以主体正文为准。

### A. 基础输入（缺一不可）

| 数据 | 必须问到的内容 | 已知来源 |
|---|---|---|
| 面板快照 | 主属性、各元素 INC、暴击率 / 暴伤、对健康 / 受伤 / 远处 / 精英 / 易伤等条件 INC | 用户提供截图则直接读；无截图则问 |
| 技能与循环 | 主技能名、等级倍率、属性与形态、是否复合伤害、是否穿插普攻、是否接受「单次命中倍率相加 ≈ 循环期望」的简化。**技能的实际跳数 / 每段倍率不内嵌，须在计算时深度调查（技能面板 / 参考网页）后按实际值代入** | 问用户 / 调查 |
| 已点天赋 / 装备全集 | 尤其所有「对某状态增伤 / 某状态触发增伤」的条件词条，及是否已计入面板 | 问用户；词条归类见主体板块二 / 三 |
| 目标模型与覆盖率 | 小怪秒杀 vs 精英持续；健康 / 受伤 / 远处 / 灼烧 / 静电 / 光环等覆盖率 | 按主体 Step 6 判定链推导，或用户实测覆盖优先 |

### B. 裁决输入（影响精度与结论方向）

| 数据 | 何时必须问 |
|---|---|
| 冲突数值的实测值 | 易伤内置百分比、普攻等级倍率（各网页分歧大，见 `data-sources.md`「普攻 / 技能数值查法」）等页面冲突时，按「来源冲突裁决」请用户游戏内核对；已裁决项见 `data-sources.md`，不再复问。独立状态乘区系数如需高精度须专门精细实测（见下「实测方案设计」） |
| 伤害组分边界 | 是否计入 DoT / 荆棘 / 爆炸等额外来源；各组分是否吃暴击、主属性、条件加成 |
| 简化假设接受度 | 暴击上限是否截断（上限值见 `known-issues.md`）、充能指环是否穿戴及平均法力（全伤与元素加算、易伤内置 30% 归独立乘区均已裁决，不再问） |

### C. 不必问（已有约定或默认值，输出时声明即可）

易伤内置 30%（独立乘区）、基础暴伤 150%、Burn 8 跳、DoT 暴击区按 1、全伤与元素 INC 加算、静电仅对雷系生效而其余独立项按各自作用范围、不同形态 INC 不相乘、非线性增益在乘区内部加权。依据见主体「代入约定」「Step 2+3」「Step 5」「Step 6」「Step 6.5」。

### 适用场景

- **跨方案配装 / 天赋对比**：换天赋、换装备、换增益覆盖后的升降判断，是本清单的核心用途。
- **强状态联动 build**：易伤 / 灼烧 / 静电 / 光环同时存在，跨乘区激活多处加成时，用于穷举联动项。
- **多目标模型对比**：小怪秒杀 vs 精英持续，覆盖率需分别推导时。
- **新职业 / 新技能建模的预处理**：清单本身通用，但已查证数值案例集中在法师，其他职业须先按清单补查机制，不得照搬法师结论。

## 实测方案设计（替提问者出实测方案）

当计算遇到来源冲突、乘区归属不明、覆盖率 / 频率待定，或需要与实测对拍时，**主动替提问者设计一组可执行的游戏内实测**，而不是只列出「请实测」的要求。实测优先于任何页面值，好的实测设计能一次裁决多个悬案。

**设计原则**

1. **单变量对照**：一次只改一个量（如点 / 取消某天赋、穿 / 脱某装备），其余锁死。对照读数能直接给出该变量的乘区效应。
2. **同状态锁定**：暴击 / 非暴击、光环期 / 非光环期、层数等必须锁到同一档再比，否则读数混杂会把不同乘区效应叠加。
3. **比值优先于绝对值**：两方案的跳字**比值**会约掉武器基数、条件区、暴击率等共有因子，只剩待考察的差异项；比绝对跳字稳健得多。观测暴击跳字时，暴击因子直接取 `1+0.5+暴伤INC`，**不含暴击率**；期望伤害才乘暴击率，二者不可混用。
4. **差法消元**：两方案技能轴 / 普攻相同时，秒伤之差 = 净新增组分的贡献（普攻等共同项自动抵消）。
5. **定标与验证分离**：先用一组读数定标未知基数，再用**独立的一组**读数验证，避免循环论证。
6. **必给判读阈值**：每个方案要写明「若结果落在 X 则结论 A，落在 Y 则结论 B」，让提问者能自行裁决。
7. **跳字比与秒伤闭合联合约束**：乘区归属这类「结构问题」用同状态跳字比裁决（约掉共有因子，只留差异项）；系数 / 层数这类「强度问题」用秒伤闭合反推。两者须联合自洽——若某归属口径在跳字定标锁定的系数下，反推出超出机制上限的层数才能闭合秒伤，即可排除该口径。定标读数须锁死层数 / 光环档位，实战秒伤则按平均层数代入，二者不可混用同一组数值。
8. **低频高峰先算贡献再决定取舍**：秒伤闭合中遇到偶发超高伤读数，不得凭「出现频率低」直接剔除。先估算「频率 × 单次伤害」占总秒伤比例——双峰 / 长尾分布下低频峰可能贡献可观份额。是否必暴、倍率多少这类问题，优先读**不暴击白字**锁定，避免暴击因子不确定导致过度拟合。

**可复用的实测模板**（按需选用）

| 目的 | 实测设计 | 判读 |
|---|---|---|
| 裁决某增伤的乘区归属（加算 vs 独立） | 同光环 / 同层数，测「点 / 取消」该天赋的暴击跳字比值 | 比值 = 加算预测（1+INC 并入条件区）→ 加算；显著更大且约等于独立因子 → 独立乘区 |
| 定标层数类乘区 | 取消其他易混淆增益，测满层与 0 层同状态跳字比 | 比值开「层数」次方得每层系数 |
| 验证某效果的触发率 | 数固定窗口内总跳数与触发次数 | 触发次数 ÷ 可触发跳数 ≈ 声明概率 |
| 求命中频率 / 技能轴 | 数固定窗口内各动作次数与总命中数 | 得每秒发数 / 跳数，供 DPS 校准 |
| 定标爆炸等额外组分的倍率 | 读该组分暴击跳字与另一已知组分跳字比 | 用比值公式反推倍率；优先读**不暴击白字**避开暴击因子不确定，只保留量级、不外推精确区间 |
| 裁决额外组分是否必暴 / 稀有峰是否可忽略 | 固定窗口数该组分跳字分布，单列偶发超高伤峰；另读常规读数中的非暴击白字 | 稳定出现白字 → 正常暴击；几乎全为暴击大字 → 必暴。先算「峰频率 × 单次伤害」占总秒伤比例，占比不足才可忽略 |
| 裁决易伤类缺口 | 测有 / 无易伤的**暴击跳字比**与**非暴击白字比** | 两比值一致 → 条件区；仅暴击比偏大 → 暴击区另有词条 |
| 验证暴击上限 | 堆暴击至面板不再上升 | 记录实际上限值 |

设计完成后，按主体「输出格式」把实测方案作为一条明确的操作步骤交付，并说明它将裁决哪个未决项。
